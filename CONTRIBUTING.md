# Contributing

Contributions are welcome through issues and pull requests.

## Before Submitting

- Discuss substantial behavior or architecture changes in an issue first.
- Keep changes focused and avoid committing local runtime data.
- Never include API keys, conversations, generated media, private knowledge-base content, or customer data.
- Add or update tests and documentation when behavior changes.
- Run the syntax, import, configuration, and relevant manual workflow checks.

## Development Setup

Follow the manual installation steps in `README.md`, create a private `config.json` from `config.example.json`, and run `python main.py`.
